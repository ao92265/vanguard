# Bundled interface fonts

Downloaded 8 September 2026 from the official upstream repositories, unmodified.

- Inter variable (normal, weights 100–900): https://github.com/rsms/inter/blob/master/docs/font-files/InterVariable.woff2
- JetBrains Mono (normal, Regular 400, Medium 500, SemiBold 600): https://github.com/JetBrains/JetBrainsMono/tree/master/fonts/webfonts

Both are distributed under SIL Open Font License 1.1. Copyright notices and full
licences accompany the assets in Inter-LICENSE.txt and JetBrainsMono-OFL.txt.
The application loads these local files and makes no runtime font CDN request.
